The CShift compiler runs here in the browser, as WebAssembly. It checks the program as you type, shows what the
name at the cursor is, and shows the LLVM IR it generates. **Run** (or Ctrl+Enter) compiles the program to WebAssembly
with the compiler's own backend and runs it, right here: nothing is sent to a server.
